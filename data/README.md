# Result tables

[Project](../README.md)

- [nutrient-loads.csv](nutrient-loads.csv): nitrogen and phosphorus loads, tonnes/year.
- [buffer-and-cost-results.csv](buffer-and-cost-results.csv): area, potential retention and costs; retains reported rounding.

These are result tables, rather than the original spatial input layers. The compensation component has no specified payment recurrence period.
