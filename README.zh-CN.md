## 从污染源分析到空间措施

缓冲带应布置在哪里，可能减少多少磷流失，不同市镇如何分担费用？本案例在 QGIS 3.44.3 中结合土地覆盖、河网、市镇边界、点源负荷与出口负荷资料，完成污染源估算和缓冲带空间筛选。

首先以土地覆盖面积及输出系数估算氮、磷面源负荷，加上点源后与流域出口负荷比较。随后选择一级、二级河流周围 20 m 范围内的耕地，计算候选缓冲带面积、磷滞留潜力及费用。

## 氮、磷负荷

| 负荷，吨/年 | 氮 | 磷 |
|---|---:|---:|
| 估算面源 | 1,707.8 | 32.7 |
| 点源 | 214.9 | 3.6 |
| 合计估算 | 1,922.7 | 36.3 |
| 出口负荷 | 2,496.0 | 51.0 |

估算总量比出口负荷分别低 573.3 吨氮/年和 14.7 吨磷/年，表明简单输出系数法仍有未解释的差额。森林占地面积最大，但耕地是磷流失控制的重要目标。

## 缓冲带选区与结果

处理顺序为：**合并河网 → 建立 20 m 缓冲区 → 融合重叠区域 → 与土地覆盖相交 → 保留耕地 → 重新计算面积**。

![缓冲区局部图](figures/buffer-detail.png)

| 项目 | 原分析结果 |
|---|---:|
| 候选缓冲带面积 | 808.8 ha |
| 潜在磷滞留量 | 3,235 kg/年 |
| 建设费用 | 13,749,855 SEK |
| 补偿费用分量 | 323,526 SEK |
| 合计费用估算 | 14,073,381 SEK |

磷滞留按 4 kg/(ha·年) 估算；建设和补偿分别采用 1.70 SEK/m² 与 400 SEK/ha。总值由未四舍五入的面积计算。原计算未注明补偿费用的重复支付周期，因此这里不把合计费用称为“年费用”。

## 四种费用分配原则

![市镇费用比例](figures/cost-allocation.png)

比较流域面积、面源磷负荷、缓冲带面积、河长四种分配依据。例如 Ängelholm 按流域面积分配时承担 17.2%，按缓冲带面积分配时为 24.6%。即使总费用不变，采用不同原则也会改变各地承担的份额。

本分析服务于初步空间筛选和方案讨论。削减量是统一系数下的潜力估算；实施时还需要结合地形、排水路径、土地可用性和实际措施效果核实。
